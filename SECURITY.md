# Security Policy

CineDesi welcomes responsible reports about security issues affecting `cinedesi.online`.

## Reporting

Use the official contact route at:

- https://cinedesi.online/contact.html
- https://cinedesi.online/.well-known/security.txt

For copyright, source, or content-rights concerns, use the separate rights-holder route:

- https://cinedesi.online/rights.html

## Please include

- A clear description of the issue.
- The affected URL or component.
- Reproduction steps.
- Potential impact.
- Any non-destructive proof needed to understand the issue.

## Please do not

- Access or download private user, subscriber, partner, or rights-request data.
- Disrupt the service or perform denial-of-service testing.
- Attempt social engineering.
- Publish sensitive details before CineDesi has had a reasonable opportunity to investigate.

CineDesi is an independent student-built project and prioritizes good-faith, responsible security reporting.
